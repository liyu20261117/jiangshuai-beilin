# 将帅碑林 · 网页专题

以石碑为载体的纪念场：五页站点 + 一个单文件 H5。

> 一百二十余亩园区、十七处露天展区、四千五百八十余块碑，镌刻 **140082** 个红军将士英名。

## 页面

| 页面 | 内容 |
| --- | --- |
| `index.html` | 首页：航拍头图、四项数据、石/名/山、四个时间刻度、四条入口 |
| `history.html` | 碑林春秋：从战场到碑林，八个节点，守碑人的“碑林长征” |
| `sights.html` | 碑的形制：纪念碑、碑墙、单碑、雕像、标志碑、石刻、浮雕、馆藏；工艺四步 |
| `names.html` | 英名长存：十四万英名、四类名录、乳名、女红军、仍在增补 |
| `visit.html` | 如何读碑：读碑四步、观展提示、现场影像、资料来源 |
| `h5.html` | 五页合并成的单文件版本（图片/视频/音频内嵌，约 16MB） |

## 设计

深色碑石底色，朱砂与铜金点缀；衬线中文标题配无衬线标签。
固定顶栏 + 顶部进度条 + 右侧圆点章节索引；滚动显现、数字滚动、首屏聚光、图片灯箱。

## 交互与声音

- 点击、悬停音效；背景音乐（首次点击后播放，右上角开关 + 音量滑杆，换页续播）
- 图片可点击放大；视频互斥播放；移动端 980/720 两级断点

## 本地预览

直接双击 `index.html`。若视频不播放：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署到 GitHub Pages

1. 新建仓库（Public），上传本目录**里面的所有文件**到仓库根目录；
2. **Settings → Pages → Deploy from a branch → main → / (root) → Save**；
3. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

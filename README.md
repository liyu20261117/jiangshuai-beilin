# 川陕苏区将帅碑林 · 网页展示

四川巴中南龛山 **川陕苏区将帅碑林** 的图文展示页：五页站点 + 一个单文件 H5。

> 全国最大的红军碑林：120 余亩园区、17 处露天展区、4580 余块碑，镌刻 **140082** 个红军将士英名。

## 页面

| 页面 | 内容 |
| --- | --- |
| `index.html` | 首页：航拍视频头图、数字、导览入口、南龛山长卷 |
| `history.html` | 碑林春秋：1932 年红军入川 → 1993 年批准建碑 → 2005 年落成 → 今日 |
| `sights.html` | 园区览胜：英名纪念碑、碑墙、单碑长廊、将领像园、标志碑、博物馆、南龛造像、飞霞阁 |
| `names.html` | 英名长存：14 万英名、乳名烈士、妇女独立营/团/师 |
| `visit.html` | 参观指南：开放信息、游览路线、现场视频、资料来源 |
| `h5.html` | 上面五页合并成的单文件版本（图片/视频/音频内嵌，约 14.5MB） |

## 交互

- 点击、悬停音效；背景音乐（Mixkit 免费素材，首次点击后播放，右上角可开关）
- 数字滚动、滚动显现、长卷视差、章节高亮
- 移动端自适应（980px / 720px 两级断点）

## 本地预览

直接双击 `index.html` 即可。若视频不播放，可在本目录执行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署到 GitHub Pages

1. 新建仓库（Public），上传本目录**里面的所有文件**到仓库根目录；
2. 仓库 **Settings → Pages**；
3. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存；
4. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。
